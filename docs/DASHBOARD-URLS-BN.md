# গোলাপি শপ ড্যাশবোর্ড লিংক

এই ঠিকানাগুলো বর্তমান `js/core/app-registry.js` এবং Netlify SPA রাউটের সঙ্গে মেলে। অনুমোদিত স্টাফ অ্যাকাউন্টে লগইন করতে হবে।

| কাজ | ঠিকানা |
| --- | --- |
| অ্যাডমিন, চার জোনের অর্ডার ও নিয়ন্ত্রণ | https://golapishop.online/admin |
| কোম্পানি OS | https://golapishop.online/company-os |
| নিজের জোনের ম্যানেজার | https://golapishop.online/zone-manager |
| ড্রাইভার ওয়েব অ্যাপ | https://golapishop.online/driver/ |

`/business-os` এবং `/bussines-os` পুরনো অ্যাডমিন লিংকের বিকল্প; নতুন করে প্রবেশ করতে `/admin` ব্যবহার করুন। এই নথি কেবল রিপোর রাউট বোঝায়; প্রকাশের পর লাইভে আলাদা করে পরীক্ষা করুন।
