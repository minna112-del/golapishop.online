গোলাপি শপ অনলাইন: বর্তমান GitHub main-এর ফাইল কাঠামোয় সম্পূর্ণ সোর্স।

এই ZIP-এ সাইটের সোর্স ও Firebase Functions আছে; dist বা node_modules নেই। ZIP নিজে রিপোতে একটি ফাইল হিসেবে আপলোড করলে Netlify সেটি দিয়ে সাইট তৈরি করতে পারবে না। ZIP খুলে ভেতরের ফাইলগুলো রিপোর root-এ একই পাথে বসিয়ে commit করতে হবে।

Netlify main-এ নতুন commit পেলে npm run build চালিয়ে dist প্রকাশ করে। Firebase Cloud Functions Netlify-তে প্রকাশ হয় না। একই প্রকল্প golapishoponline-এ Firebase CLI দিয়ে `firebase deploy --only functions` চালাতে হবে। Firestore Rules-এ পুরোনো নিয়ম থাকলে `firebase deploy --only firestore:rules` বা Firebase Console থেকে এই রিপোর firestore.rules প্রকাশ করতে হবে।

ওয়েব ও Functions আলাদা সিস্টেম, তাই দুটো deploy কাছাকাছি সময়ে শেষ করুন। তারপর একটি পরীক্ষামূলক COD অর্ডার, কাস্টম বাজারের প্রতিটি জোনে একটি করে পরীক্ষা, admin payment verify ও driver assignment, Company OS notification পরীক্ষা করুন। লাইভ পরীক্ষা না হওয়া পর্যন্ত অর্ডার নেওয়া নিশ্চিত ধরে নেবেন না।

রিপোর build ও check পাস করলেও নতুন কোড প্রকাশ না করলে লাইভ সাইট বদলাবে না। প্রকাশের পর আসল অর্ডার, ম্যানুয়াল পেমেন্ট দেখা, জোন ম্যানেজারের ড্রাইভার অ্যাসাইন এবং ফোনে নোটিফিকেশন পরীক্ষা করুন।
