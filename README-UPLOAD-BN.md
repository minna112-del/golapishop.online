# গোলাপি শপ: রিপোতে আপডেটের ক্রম

এই প্যাকেজে মূল আপলোড করা সোর্সের তুলনায় বদলানো ফাইলগুলো আছে। ZIP ফাইলটি GitHub রিপোতে অপরিবর্তিত অবস্থায় রাখবেন না; unzip করে প্রতিটি ফাইলকে একই আপেক্ষিক পাথে বসাতে হবে। উদাহরণ: `js/router.js` পুরোনো `js/router.js`-এর জায়গায়। `golapishop.online` বা অন্য কোনো নতুন wrapper folder তৈরি করবেন না।

1. পরিবর্তিত ফাইলগুলো রিপোর root, `js/`, `js/core/`, `pages/`, `functions/`, `docs/`-এ একই নামে বসিয়ে commit করুন। বিদ্যমান অন্য ফাইল মুছবেন না। `firestore.rules`-ও রিপোতে রাখুন, যদিও Console-এ আপনি ইতিমধ্যে Rules প্রকাশ করেছেন; এতে পরবর্তী Firebase deploy-এ পুরোনো Rules ফিরে আসবে না।
2. Netlify-তে ওই commit-এর build সফল হয়ে `Published` দেখালে আগে `https://golapishop.online/company-os`-এ লগইন ফর্ম, তারপর অ্যাডমিন লগইন পরীক্ষা করুন। লাইভে সফল না দেখা পর্যন্ত লিংক কাজ করছে ধরে নেবেন না।
3. Firestore Rules Console-এ প্রকাশ করলেও `functions/index.js`-এর callable অর্ডার/পেমেন্ট সংশোধন এবং `onOrderCreated` পুশ ট্রিগার deploy হয়নি। একই Firebase প্রকল্পে Firebase Functions আলাদাভাবে deploy করুন। Blaze billing plan লাগতে পারে।
4. ফোনে নোটিফিকেশন চালু করে ভিন্ন ফোন থেকে চারটি জোনে COD এবং কাস্টম বাজারের পরীক্ষামূলক অর্ডার দিন। কাস্টম বাজারে ট্রানজেকশন ID ম্যানুয়ালি মিলিয়ে দেখুন; পেমেন্ট স্ট্যাটাস নির্বিশেষে ম্যানেজার নিজের জোনে ড্রাইভার অ্যাসাইন করতে পারবেন। পরীক্ষামূলক অর্ডার পরে অ্যাডমিন থেকে বাতিল করুন।

Firebase Auth UID ও `staff/{uid}`-এর `role: admin`, `active: true` আগেই যাচাই হয়েছে বলে এগুলো বদলানোর প্রয়োজন নেই। লগইন ফর্মের ফাঁকা পাতা কোডের সমস্যা; Rules দিয়ে ঠিক হবে না।
